Ratebook has an MCP server, so AI tools that support the Model Context Protocol (such as Claude Desktop) can read your rate cards and prepare changes.

## Create a token
Open Connect, give the token a name, and create it. Copy it right away: it is shown only once. A token can never do more than your own role allows.

## What connected tools can do
They use the same tools as the in-app assistant. Changes they prepare wait on the Changes page until someone approves them in Ratebook.

## Revoke a token
Revoke it on the Connect page; it stops working immediately.
