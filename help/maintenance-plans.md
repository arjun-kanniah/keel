A maintenance plan is an item customers buy once a season or once a year that covers a set number of visits.

## Set up a maintenance plan
Add it as an item in the right folder with the type Maintenance and the unit "per year" (or "per season"). Put the number of visits it covers in the name or the note, for example "Winter furnace plan (2 visits)".

## Choosing a price
A common starting point is the price of the visits it covers with a 10–15% discount. The assistant can suggest a price from your existing maintenance items.
